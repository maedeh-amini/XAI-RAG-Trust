# Academic Corpus (Chunked Data) - Public Sample

**File:** `academic_corpus_chunks_sample.json`

### Data Sharing Restriction Notice
Due to institutional data privacy and copyright restrictions regarding Osnabrück University's internal documents, the full vector database corpus cannot be published in this public repository. 

The provided JSON file contains a structural sample of **10 chunks**. The complete dataset used to build the databases for the RAG pipelines contains **7,866 chunks**. 

This sample is provided solely to demonstrate the data schema, the chunking strategy, and the metadata formatting (e.g., source document referencing) required to execute the experimental RAG pipeline code.
